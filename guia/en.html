// THE GAME

Every crash is different

A mix of platforming and boss shooting, with an 80s neon look and 1990-style flat-shaded 3D polygons.

◇◆◇

Bosses built from parts

Head, eyes, mouth, body, arms, legs and back: 2,187 combinations. Legs, arms and eyes change how the boss moves and attacks.

▤▤▤

Cover made of wreckage

When you crash, your ship breaks apart. Each piece lands on the map and becomes a metal hull platform that cracks under fire.

◎ ◎

The intro warns you

The planet takes the boss's colours, eyes glint on its dark side and a long-range scan reveals the enemy's name and abilities.

⇄ ⇄

Co-op everywhere

Two players on one keyboard, two handhelds on the same network, two browsers over the internet, or browser with handheld.

// INSTALL

Install on the RG35XX H

The game runs on the LÖVE engine and installs through PortMaster, which comes with muOS. It's one zip; PortMaster does the rest.

  • Anbernic RG35XX H with muOS
  • PortMaster installed
  • Wi-Fi for the first install
  • The SD card in a computer

  1. Download the package

    crashlanders.zip — don't unzip it.

  2. Copy it to the card

    Put the zip in the SD card's MUOS/PortMaster/autoinstall/ folder (the autoinstall folder inside PortMaster's folder).

  3. Open PortMaster on the handheld

    It finds the zip and installs the game by itself. The first time it also downloads the LÖVE 11.5 runtime, so the handheld needs Wi-Fi.

  4. Play

    The game shows up under Ports as Crashlanders. Saves and scores are kept inside the game's folder.

Optional fonts: by default the handheld version uses LÖVE's built-in font. To match the browser version, copy the Orbitron, VT323, Mr Dafoe and Share Tech Mono TTFs (Google Fonts, OFL licence) into crashlanders/gamedata/assets/fonts/.

// MULTIPLAYER

Play together, wherever you are

In every networked mode one device is the host: it runs the game and sends its state to the other about 30 times a second. The guest only sends the buttons it presses. It's cooperative: both of you against the boss. Menu names below are as they appear in the game.

LOCAL

On one device

browserhandheld

Choose 2 JOGADORES (2 players) in the menu. In the browser each player uses half of the keyboard. On the handheld, player 2 plugs a gamepad into the USB-C port.

LAN

Handheld with handheld

handheldPC with LÖVEsame network
  1. Both devices on the same Wi-Fi.
  2. On one: LAN · CO-OP → CRIAR JOGO (create game).
  3. On the other: LAN · CO-OP → PROCURAR JOGO (find game) and pick the host.

ONLINE

Browser with browser

browserany network
  1. One player picks ONLINE · CO-OP → CRIAR SALA (create room) and gets a 4-letter code.
  2. The other picks ENTRAR COM CÓDIGO (join with code) and types it.
  3. The intro starts when both are in the room.

CROSS-PLAY

Browser with handheld

browserhandheldrelay on a PC

The handheld can't join browser rooms directly. A small program on your PC, the relay, bridges the two. See the steps below.

The relay joins the online room on the handheld's behalf and passes messages both ways. Browser and handheld share the same 4-letter rooms, and either one can host.

Start the relay (once per session)

  1. On a PC on the same network as the handheld

    You need Node.js 22 or newer and the game's source (the relay/ folder).

    $ cd relay
$ npm install
$ npm start
relay listening on tcp 47240 (LAN 192.168.1.x)

  2. On the handheld

    LAN · CO-OP → PROCURAR JOGO. The relay shows up as ONLINE (relay …). Pick CRIAR SALA (the code appears on screen) or ENTRAR COM CÓDIGO (choose the letters with the D-pad).

  3. In the browser

    ONLINE · CO-OP and join the room with the same code, or create the room yourself and give the code to the handheld player.

// HELP

Troubleshooting

The game doesn't show up in Ports after copying the zip

Check that the whole zip (not unzipped) is inside PortMaster's autoinstall folder, then open PortMaster once. On the first install the handheld needs Wi-Fi to download the LÖVE runtime.

The screen stays black when the game starts

This usually happens when the .sh or .lua files were saved with Windows line endings (CRLF). Always use the zip from this page or from build_zip.py, which forces Unix line endings. The startup log is in ports/crashlanders/log.txt.

The list under PROCURAR JOGO stays empty

Both devices (or the handheld and the relay PC) must be on the same Wi-Fi network. Some guest networks isolate devices from each other. On the PC, allow Node.js and LÖVE through the firewall: the game uses UDP ports 47231 (discovery) and 47232 (LAN game) and TCP port 47240 (relay).

The online room won't connect ("Erro de ligação")

Online rooms use a free Supabase project, which is paused after a few days without use. When that happens it has to be restored in the Supabase dashboard; the browser leaderboard comes back too.

There's lag when playing online

The guest sees the game with the latency of its connection to the host (usually 50–150 ms). Since it's cooperative this matters little, but the player with the steadiest connection should host.

Do my single-player upgrades disappear after playing online?

No. LAN and online games never touch the local save, so your single-player progress stays as it was.
